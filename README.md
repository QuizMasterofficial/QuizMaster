# QuizMaster
An interactive web-based quiz application developed using HTML, CSS and JavaScript, featuring multiple difficulty levels, timed questions and score tracking.
# QUIZMASTER – ONLINE QUIZ SYSTEM

## 1. Introduction

QuizMaster is an interactive web-based quiz application developed to allow users to test their knowledge through multiple-choice questions. Users can select a difficulty level, answer questions within a given time and view their results at the end of the quiz.

## 2. Objectives

- To develop an interactive online quiz system.
- To provide different difficulty levels.
- To test users' knowledge through multiple-choice questions.
- To display scores and performance feedback.
- To allow users to review their answers after completing a quiz.

## 3. Tools and Technologies Used

**HTML (HyperText Markup Language):** Used to create the structure and content of the website.

**CSS (Cascading Style Sheets):** Used to style the website, including colours, layouts, buttons and responsive design.

**JavaScript:** Used to implement the quiz functionality, including question selection, countdown timer, answer checking, score calculation and results.

**Visual Studio Code:** Used as the code editor for writing and managing the project files.

**Google Chrome:** Used to run, view and test the application.

**GitHub:** Used to store the source code and publish the website online through GitHub Pages.

## 4. Development Procedure

1. Created a project folder for the QuizMaster application.
2. Created the main project files: `index.html`, `style.css` and `script.js`.
3. Used HTML to build the quiz interface.
4. Used CSS to style the interface and make it responsive on mobile devices.
5. Used JavaScript to create the question bank and quiz functionality.
6. Added difficulty selection: Easy, Medium and Hard.
7. Implemented random question selection and a 20-second countdown timer.
8. Added answer checking, score tracking and a progress bar.
9. Developed the results screen with performance feedback.
10. Added an answer review section and restart functionality.
11. Tested the application in a web browser and corrected errors.
12. Uploaded the project files to GitHub and published the website using GitHub Pages.

## 5. Procedure for Executing the Application

### A. Local Execution

1. Open the QuizMaster project folder in Visual Studio Code.
2. Ensure that `index.html`, `style.css` and `script.js` are in their correct locations.
3. Open `index.html` in a web browser or use the Live Server extension.
4. Select a preferred difficulty level.
5. Answer the questions within the allocated time.
6. View the final score and review the answers.

### B. Online Execution

1. Open the published website using the link below:

   https://quizmasterofficial.github.io/QuizMaster/

2. Select a difficulty level.
3. Answer the multiple-choice questions.
4. View the final score and performance feedback.
5. Review answers or restart the quiz.

## 6. Main Features

- Three difficulty levels: Easy, Medium and Hard.
- Random question selection.
- Four answer options per question.
- 20-second countdown timer.
- Automatic answer checking.
- Score counter and progress bar.
- Final results and performance feedback.
- Answer review section.
- Restart quiz functionality.
- Responsive interface for mobile devices.

## 7. Conclusion

QuizMaster demonstrates how HTML, CSS and JavaScript can be combined to develop an interactive web-based quiz application. The project provides users with a simple way to test their knowledge while demonstrating fundamental web development concepts.
